# AgroSezon — История создания и путь к iOS

**Дата создания:** 6 ноября 2026  
**Автор:** Дмитрий Эполетов  
**Проект:** Сезонный календарь овощей, зелени, фруктов и ягод

---

## Что уже сделано

1. **Портфолио-сайт** с интерактивными прототипами:
   - Проект 01 — «Хвостики» (груминг)
   - Проект 02 — «AgroSezon»

2. **Приложение AgroSezon**:
   - Поддержка русского и английского языков
   - Переключатель темы (светлая/тёмная)
   - Выбор региона → страны → климатической зоны → месяца
   - Категории: Овощи, Зелень, Фрукты, Ягоды
   - Статусы сезона (начало / пик / конец)
   - Поиск по продуктам

3. **Capacitor-проект**:
   - Папка `android` — готова
   - Папка `ios` — подготовлена
   - `capacitor.config.json` настроен
   - Иконки и splash screen сгенерированы

4. **Android APK**:
   - Debug APK собран
   - Путь: `android/app/build/outputs/apk/debug/app-debug.apk`

## Что нужно для продолжения на iOS

### Требования
- Mac с установленным Xcode
- Apple Developer аккаунт (для установки на реальные устройства и публикации)

### Шаги на Mac

1. Скопировать всю папку проекта на Mac
2. Открыть терминал в папке проекта и выполнить:
   ```bash
   npm install
   npx cap sync ios
   npx cap open ios
   ```
3. В Xcode:
   - Выбрать свою команду разработчика
   - Настроить Bundle Identifier
   - Выбрать устройство или симулятор
   - Нажать Run (или Archive для .ipa)

### Альтернатива (без Mac)
- Использовать облачные CI/CD: Codemagic, Bitrise, MacStadium
- Попросить кого-то с Mac собрать проект
